## 0. 测试口径

### 0.1 环境

| 项 | 值 |
|---|---|
| 主环境 | Android 7.1 云手机（截图同环境） |
| 兼容验证 | Android 10、Android 13、Android 14 各一台 |
| 被测目标应用 | 自制探针 App：全屏按钮 + 记录每次 `MotionEvent` 的 (x, y, 时间戳, 持续时长)，可导出 CSV |
| 系统应用 | 设置、权限控制器、桌面（用于误点拦截验证） |

### 0.2 判定工具

- **点击是否发生**：以探针 App 的 CSV 为准，不靠肉眼；
- **时序误差**：时间戳对齐，允许 ±15ms；
- **坐标误差**：允许 ±1px（抖动开启时按抖动范围判定）；
- **状态断言**：会话状态、`stop_reason`、`paused_reason` 需可在调试页看到或导出。

### 0.3 优先级

| 级别 | 含义 |
|---|---|
| P0 | 主流程或安全红线，失败即不能发布 |
| P1 | 重要功能或常见异常路径 |
| P2 | 体验细节 |

### 0.4 本轮变更带来的前提

| 前提 | 说明 |
|---|---|
| 点位间隔默认 **1000ms**，可自由设定（0~60000） | 与截图一致 |
| 垃圾桶 = **彻底删除按钮** | 被其他方案引用时先确认，确认后级联移除对应步骤 |
| 隐藏收纳进**悬浮球** | 悬浮球是唯一常驻入口，工具条显隐由它控制 |
| 目标应用**自动识别 + 一次确认** | 用户打开目标 App 后自动提示绑定 |
| 循环轮次在**保存面板**填写 | 截图无此入口 |

## 8. 冒烟用例（每次构建必跑，约 15 分钟）

1. 打开面板 → 创建方案 → 绑定应用（M1-12、M2-02）
2. 加 3 个点 → 拖动 1 个 → 保存并设 2 轮（M2-07、M2-10、M4-11）
3. 启动 → 跑完 → 断言点击次数 6（M5-07）
4. 再跑一次，中途点悬浮球停止（M5-09）
5. 运行中切到桌面，断言暂停（M5-12）
6. 杀进程重启，断言数据与状态都正常（M5-20、M7-01）
